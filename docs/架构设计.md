## 二、数据模型（5 张业务表 + 1 张设置表）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `knowledge_points` | **subject**, name, grade, chapter, **prereqs(JSON)** | 知识图谱节点；支持按科目/年级筛选，prereqs 存前置知识点名，构成有向无环图（过滤时跨幅边剪枝） |
| `questions` | question_text, my_answer, analysis(JSON), variants(JSON), status, error_type, review_stage/next_review_at | 错题；analysis 由 AI 生成（解法/错因/知识点/教材定位），variants 为举一反三 |
| `papers` | questions(JSON 逐题得分), analysis(JSON) | 试卷；逐题含知识点标注，analysis 为纵向分析结果 |
| `workbooks` | name, catalog(JSON) | 练习册目录库：章节→页码→知识点，支撑错题定位 |
| `study_plans` | plan_data(JSON) | 生成的计划：按天的任务列表（知识点/动作/关联错题/打卡状态） |
| `app_settings` | key/value | 网页设置的 AI 后端配置（优先于 .env） |

## 三、关键技术设计

### 1. AI 多后端接入（`services/ai_client.py`）

- 统一走 **OpenAI 兼容协议**，`base_url` / `api_key` / 视觉模型 / 文本模型均可配置；
- 配置来源两级：网页「设置」页（存 `app_settings` 表）> `backend/.env`；
- `extract_json()` 稳健解析：先尝试 markdown 代码块 → 整体 → 花括号配平截取；失败时携带原输出追问一轮"只输出 JSON"；
- 未配置 Key 抛 `AINotConfigured` → API 返回 503 + 中文指引；调用失败统一包装为 `AIServiceError` → 502。**除 AI 三个端点外全部功能离线可用**，保证可演示性。

### 2. 掌握度估计（`services/knowledge.py`）

对每个知识点，取两类信号中**较保守者**（宁可高估薄弱）：

- **错题信号**：该知识点所有错题的状态均值（未解析 0.25 / 复习中 0.5 / 已掌握 0.9）
- **试卷信号**：`0.9 − 0.6 × 失分率`，按考试日期推进覆盖（最近一次考试代表当前水平）

无证据的知识点返回"未知"，**不视为薄弱**（避免把没做过的题当弱点）。

### 3. 学习计划排程算法（`services/plan_service.py`）★ 核心创新

```
输入：错题记录 + 历次试卷
① 汇总证据：未掌握错题的知识点 ∪ 试卷失分率≥30% 的知识点
② 筛薄弱点：掌握度 < 0.65
③ 前置闭包：沿 prereqs 边回溯祖先，纳入其中"确有证据且薄弱"的
④ 拓扑排序：前置知识层级高的先排；同层级按掌握度升序（最弱优先）
⑤ 生成任务：概念巩固(教材章节) → 错题重做(关联错题) → 举一反三(变式+练习册定位)
⑥ 分配到天：每天≤3个任务(约40分钟)；最薄弱2个知识点在末尾追加"间隔复测"(艾宾浩斯)
输出：按天的计划任务列表
```

> 工程注意：实现时踩过 CPython `list.sort()` 排序期间列表被临时置空的陷阱——
> key 函数内不能调用 `lst.index()`，需预构建索引字典/层级表。（已写入测试）

### 4. 复习打卡（艾宾浩斯间隔）

`fail` → 1 天后再练；`pass` 沿 **1 → 3 → 7 天**推进，连续 3 次通过转"已掌握"；任何一次失败回到起点。计划页勾选"错题重做/复测"会同步记一次复习通过，形成**数据闭环**。

### 5. 试卷纵向分析（`services/paper_service.py`，纯算法）

- 薄弱点 = 按知识点聚合的失分/总分别排序；
- 趋势 = 历次考试得分率序列（ECharts 折线）；
- 结论（规则化中文）：
  - 与上一场考试比得分率变化 ±N 个百分点；
  - 知识点失分率变化 ≥0.15 记为"明显进步/退步"；
  - TOP3 薄弱点引导生成学习计划。

### 6. 错题↔练习册定位（差异化功能）

- 错题可标注来源练习册 + 页码题号；
- 练习册目录库：`[{章节, 页码, 知识点[]}]`（可从目录页拍照让 AI 生成草稿后修正）；
- 反向查询 `/api/workbooks/locate?kp=知识点` → 精确/包含匹配 → 返回"去哪本练习册哪几页练什么"。

## 四、安全与合规设计

- API Key 仅存本地（SQLite/​.env），接口只返回掩码（`sk-t****7890`）；
- 评审材料不含学校名称/校徽/指导教师信息（匿名要求）；
- 演示数据均为自编题目，不含第三方版权内容；
- AI 输出仅供学习参考，界面明示"参考答案/解析"性质。
