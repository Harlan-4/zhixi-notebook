# 智析错题本

> AI + 开源 的中学生错题管理与学习规划平台（响应式网页应用）
>
> 参赛方向：开源赋能的 AI 应用创新（教育学习场景）

## 作品简介

面向中学生的错题全流程管理工具：**拍照录入 → AI 识别与错因解析 → 举一反三变式 → 试卷纵向进步分析 → 知识图谱驱动的学习计划**，五个环节形成闭环。

### 核心功能

| 功能 | 说明 |
|---|---|
| 📷 错题录入 | 拍照/上传题目图片，多模态大模型识别题干（LaTeX 公式），可手动修正；也支持手动录入 |
| 🤖 AI 解析 | 生成正确解法、错因归类（概念不清/计算失误/审题错误/方法未掌握）、知识点标注、教材章节定位、易错提醒 |
| ✨ 举一反三 | 四步教学法阶梯：**同构填步题**（关键步骤挖空补全）→ 基础/提高两道独立变式（附解析），针对同一易错点设陷阱 |
| 📊 试卷分析 | 录入逐题得分，按知识点统计失分；对比历次考试给出"进步/退步知识点"与薄弱点 TOP（纯算法，离线可用） |
| 📅 学习计划 | 基于知识图谱**前置依赖关系**排程：薄弱点的前置知识优先补，按知识点"课型"差异化任务方式，融合艾宾浩斯间隔复测（自主实现的排程算法） |
| 🕸️ 知识图谱 | 按科目（数学/物理/化学/生物）与年级（初一~高三）筛选查看；已收录初高中数学 102 个知识点 + 前置依赖边（团队自主整理，含"概念/计算技能/综合应用"课型），按掌握度着色，节点可看 AI 迷你微课讲解 |
| 🧭 学习者画像 | 错因分布、高频薄弱点、考试趋势与个性化建议（纯算法，随数据自动更新） |
| 🔁 因材施教 | 错题解析支持"换种讲法"（回到定义/生活类比/拆小步骤/从错误倒推/考试视角）；重做答案可交 AI 批改核验（数学等价即算对）后自动记录复习 |
| 🖨️ 打印与复盘 | 错题重做清单 / 学习计划一键打印（A4 版式、重做勾选框、订正栏、签字栏）；周复盘思维导图（知识点 → 错因分布 / 掌握现状 / 任务完成度） |

### 差异化创新点

1. **错题 ↔ 练习册定位**：练习册目录库 + 错题来源标注 + 知识点反查（"这个知识点薄弱 → 去《某练习册》第21章 P1-P36 练题"），开源界尚无同类实现；
2. **知识图谱前置驱动的学习计划**：不是简单"隔 1/3/7 天重复"，而是先补薄弱点的前置知识（拓扑排序），再攻薄弱点，最后间隔复测；
3. **多试卷纵向进步分析**：逐题得分 → 知识点失分率 → 跨考试对比"明显进步/退步"；
4. **五功能一体化闭环**：录入→解析→图谱→学情→计划全链路打通；
5. **错因证据分级**（借鉴 good-learning-skill 的严谨性原则）：AI 解析区分"有作答证据的确认错因"与"推测错因"，推测时自动给出诊断性追问，不替学生编造错因。

## 技术栈（全部开源组件）

- **后端**：Python + FastAPI + SQLAlchemy + SQLite
- **前端**：Vue 3 + Vite + Element Plus + ECharts + KaTeX
- **AI**：OpenAI 兼容协议，**多后端可配置**（智谱 GLM-4.5V/GLM-4.6、通义千问 Qwen-VL、DeepSeek、本地 Ollama 等开源权重模型均可接入）；网页"设置"页可视化切换
- **可选本地 OCR**：PaddleOCR / Pix2Text（`requirements.txt` 中注释项，按需安装）

## 快速开始

### 环境要求

- Python ≥ 3.10，Node.js ≥ 18

### 1. 启动后端

```bash
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt     # Windows
# Linux/Mac: .venv/bin/pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

首次启动自动建库，并导入知识图谱与演示数据（**高一上学期示例**：4 道错题——基本不等式/集合子集/指数运算/对数运算，2 张试卷——月考74分→期中82分构成进步趋势，1 本练习册目录）。

### 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 http://localhost:5173

### 3. 配置 AI（可选但推荐）

进入网页「设置」页，填入任一 OpenAI 兼容服务的 API Key（如智谱 https://open.bigmodel.cn/api/paas/v4 ），点「测试连接」。

> 未配置 Key 时：识题/解析/举一反三返回友好提示，其余功能（错题管理、试卷分析、学习计划、知识图谱、演示数据浏览）**全部可用**。

### 4. 运行测试

```bash
cd backend
.venv\Scripts\python -m pytest tests/ -v
```

8 个冒烟测试覆盖：种子数据、图谱结构、错题增删改查与复习打卡、试卷分析与趋势、**计划排程的前置优先断言**、练习册定位、设置读写、统计概览。

## 已知限制

- AI 识题依赖所配置模型的多模态能力，手写体识别准确率受图片质量影响；
- 知识图谱已收录初中数学全学段（人教版）与高一上学期（人教A版必修第一册）；物理/化学/生物等科目的图谱框架已就绪，数据持续扩充中；
- 试卷识别按"一页一图"设计，多页试卷请分页上传后合并。
